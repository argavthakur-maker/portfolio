# Argav Thakur — Portfolio

A personal portfolio highlighting my work in software engineering, artificial intelligence, and computer science. It brings together selected projects, technical interests, learning milestones, and professional resources in one place.

## Preview locally

The website is a static HTML page. You can open `index.html` directly in a browser, or serve the repository locally:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Repository contents

- `index.html` — portfolio website and page styling.
- `argav.jpg` — profile image used by the portfolio.
- `Argav-CV.pdf` — current résumé document.
- `cert-*.pdf` / `cert-*.png` — selected certification and event credentials.

## Design

The page uses a responsive, warm-neutral visual system with custom CSS, Google Fonts, and icon libraries loaded from their respective CDNs. No frontend build step is required for the current static page.
